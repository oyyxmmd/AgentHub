## 新功能

- **生态接入 Claude 四档模型独立配置**：注册 CC Switch 条目时 Sonnet / Opus / Haiku / 子代理四档可分别选择不同模型（新增四行下拉），留空的档跟随默认模型（旧行为完全兼容）；Claude Code 条目分档写入 env 五组键，Claude Desktop 条目四档角色路由逐档映射（子代理档即第四档 Fable），菜单显示名逐档与该档模型同步；选择即持久化，重新注册即同步
- **合并上游 v1.45.0 → v1.60.0**（149 个提交）：新增 **LobsterAI（网易有道龙虾）**、**ModelScope（魔搭）**、**CatPaw（美团）** 三个反代渠道；记忆索引重建 / 清单构建 worker 化（不再卡主进程）；休眠唤醒守卫（唤醒瞬间签到等周期任务不再集中爆发）；全局日志脱敏（JWT/Bearer 等凭据落库前打码）；适配器契约固化 + 启动期守卫；空流判定修复（上游 200 无内容不再被当成功死磕一个号）；总览/用量统计页实时刷新；按渠道自动签到规则（每渠道独立时间 + 抖动 + 跨午夜补跑）与渠道启闭
- **托盘面板支持手动指定渠道网关账号**：账号积分卡按渠道分组展示，**点击账号行即一键切换**该渠道的网关调度账号（写 `proxy.pinnedAccount`，保存即热生效无需重启）；点击当前指定账号即取消指定、恢复策略调度。指定账号冷却/耗尽/停用时自动回落原策略选号，不会把请求打进死号
- 渠道标题行常显「调度 → 账号名」：已指定时显示指定账号，未指定时按渠道策略（到期优先/余额优先/轮询）推算显示下一个会被选中的账号，切换后立即可见
- 号池页账号行新增「网关指定」徽标，主窗口可见当前指定状态
