# v1.45.4 更新说明

本版在 `v1.45.3`（已合并上游 `v1.81.0`）基础上，补齐「内置优先」总闸与提供商路由消歧，并修复三处实际使用中暴露的问题。

## 模型路由

- **内置优先总闸**（反代网关 → 自定义提供商页 / 托盘面板均可切换）：关闭时内置渠道完全不参与自动路由，只走自定义提供商；开启后内置渠道恢复参与。两处入口都走独立 IPC 读改写，不会再出现「改完开关自己弹回来」。
- **提供商同名裸模型按优先级消歧**：多家提供商声明同一个裸模型名时，只有**唯一最高**优先级的那家胜出；同级歧义不猜，落回常规路由而不是按创建顺序随便挑一家。
- **代理模型名（proxyModel）收敛到模型行**：显式「平台名 → 本供应商模型」映射挂在 `models[]` 每一行上，同一提供商内唯一；供应商级旧字段保存时自动清空。

## 修复

- **Trae 模型名大小写**：上游 `config_name` 大小写敏感，而官方目录里是 `minimax-m3.1-flash`、客户端传的是显示名 `minimax-M3.1-Flash`，未命中映射表时被原样透传，导致 `We're sorry, the param is invalid`。现在未命中映射会回查官方目录取权威 id。
- **托盘指定账号被静默覆盖**：`pickAccount` 的防惊群让位（100ms 内不重复选同一账号）会把用户点名的账号换掉，使「指定」看起来无效。现在显式指定不参与让位；指定账号不可用时仍正常回落策略调度。
- **托盘面板跟随界面缩放**：面板与主界面同 origin，dev（`http://localhost`）下 Chromium 的 zoom 会按 origin 传播，导致面板 CSS 视口被压成 `380/缩放因子`，布局被挤压。现在按同一因子同步面板缩放与窗口尺寸，CSS 视口恒为 380×540。

## 提供商与模型目录

- **拉取模型时补齐元数据**：从公开目录（models.dev）补上下文窗口与输出上限，已存在的行只填空白、不覆盖用户手填值。
- **厂商目录映射**：拉取时把官方名与历史别名一并带进新行。
- **OpenCode Go 地址迁移**：旧地址 `/zen/go` 只提供目录、Chat 实际在 `/inference/go/openai`，写入侧统一迁移到官方 Chat 根。
- **每把 Key 独立的余额查询结果**，不再互相串值。

## 生态接入

- **上下文窗口声明**：`contextWindow` 达到 1M 才写 `[1m]` 后缀与 `ANTHROPIC_BETAS`；低于门槛时主动摘掉此前写过的后缀与 beta，避免从 1M 模型切回 200K 模型后客户端仍按 1M 判定窗口而直接 400。
- **默认思考强度**：写入 `CLAUDE_CODE_EFFORT_LEVEL`，留空时删除该键而不是写空串（空串会被客户端当作「已设置但无值」的档位）。

## 本 Fork 保留能力

- WorkBuddy CN 积分任务自动化（猫猫旅行 / 夜猫子 / 活跃地图 / 开学季）及定时任务。
- Trae SOLO CN OAuth 修复：官方 icube 设备身份、四变体换令牌、完整诊断日志。
- Trae 模型目录按 function 全量拉取，并合并上游非模型条目过滤。
- 托盘 iStat 信息面板、网关账号一键切换和 Claude 四档模型独立配置。
- macOS Apple Silicon dmg/zip 打包与 Windows 安装包发布。

## 说明

- 账号 token 经系统级加密后落盘，只在主进程流转；网关 API Key 只保存 SHA-256 哈希。
- 提供商列表在主进程内有缓存，正常经界面保存会自动失效；若用外部脚本直接改数据库，需重启网关才会生效。
